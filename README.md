# 真人帮 SkillS：本地双设备完整测试

本目录是可独立运行的本地端。启动后，电脑负责运行 Node.js 后端、SQLite 数据库、前端页面和 WebRTC 信令服务；启动器还会创建临时 HTTPS 地址，让电脑与手机打开同一个应用。

## 一键启动

双击 `启动SkillS本地版.cmd`。启动器会自动：

1. 检查 Node.js 24。
2. 清理本项目上次遗留的服务。
3. 在 `0.0.0.0:8787` 启动前后端。
4. 检查 `/api/health` 和 `/front`。
5. 获取局域网 IPv4 地址。
6. 通过 `tools/cloudflared.exe` 创建临时 HTTPS 地址。
7. 打开浏览器并显示双设备测试地址。

保持启动窗口开启。关闭窗口后，本地服务和临时 HTTPS 地址会停止。

## 使用哪个地址

窗口会显示：

- 本机：`http://127.0.0.1:8787/front`
- 局域网：例如 `http://192.168.1.8:8787/front`
- 推荐：例如 `https://xxxx.trycloudflare.com/front`

完整测试时，电脑和手机都打开同一个推荐 HTTPS 地址。它支持订单、聊天和手机摄像头/麦克风权限。

临时 HTTPS 地址每次启动可能不同，不要保存旧地址。始终使用本次窗口显示的地址。

若 HTTPS 创建失败，可让电脑和手机连接同一 Wi-Fi 后使用局域网地址。局域网 HTTP 可测试订单、接单、聊天、结束服务和评价；手机视频通常需要 HTTPS。

## 测试准备

1. 电脑和手机保持联网。
2. 两端打开同一个 HTTPS 地址。
3. 使用 Chrome、Edge、Safari 等现代浏览器。
4. 首次视频测试时允许摄像头和麦克风权限。

## 双设备订单测试

### 手机发布

1. 手机作为求助者进入应用。
2. 填写标题、详情、标签和价格并发布。
3. 手机进入 `matching` 等待页面。
4. 此时电脑不要接单，至少等待 15 秒。

正确结果：手机始终等待，不会因倒计时、点击匹配动画或旧模拟流程自动进入接单确认或聊天。

### 电脑接单

1. 电脑切换为服务者。
2. 首次使用时完成本地演示技能资料与模拟验证。
3. 进入接单广场；订单列表约每 1.5 秒刷新。
4. 打开手机发布的订单并点击接单。

只有服务者实际接单后，手机才会轮询到 `accepted`，自动从 `matching` 进入同一个聊天会话。

## 聊天测试

1. 手机发消息，电脑约 1 秒内看到。
2. 电脑回复，手机约 1 秒内看到。
3. 刷新任意一端，SQLite 中的消息应恢复。
4. 结束订单后，双方不能继续发送消息。

## 视频测试

1. 必须先完成真实接单。
2. 两端进入同一聊天会话并打开视频指导。
3. 两端允许摄像头和麦克风权限。
4. 验证本地/远端画面、静音、摄像头开关和手机前后摄像头切换。

视频使用原生 WebRTC，后端只交换 SDP/ICE。默认使用公共 STUN；校园网、公司网或复杂 NAT 可能需要 TURN。在 `Back/.env` 中添加：

```text
TURN_URL=turn:你的TURN服务器:3478
TURN_USERNAME=用户名
TURN_CREDENTIAL=密码
```

保存后重启启动器。

## 结束订单与评价

1. 在服务会话中结束服务。
2. 双方状态同步为 `completed`。
3. 消息和 WebRTC 接口拒绝继续服务。
4. 求助者填写星级、评价和匿名案例授权。

## AI 配置

模型读取 `Back/.env`：

```text
LLM_API_KEY=你的密钥
LLM_BASE_URL=兼容OpenAI接口的地址
LLM_MODEL=模型名称
```

不要提交真实密钥。未配置或调用失败时，部分功能使用本地规则回退；必须依赖模型的功能会明确提示不可用。

## 数据、日志与前端迭代

- 数据库：`Back/data/skills.sqlite`
- 服务日志：`runtime/server.out.log`、`runtime/server.err.log`
- 隧道日志：`runtime/tunnel.out.log`、`runtime/tunnel.err.log`
- 进程文件：`runtime/*.pid`

修改 `Front` 中的 HTML、CSS、JS 后，刷新浏览器即可看到结果。修改 `Back/src/server.mjs` 后，关闭启动窗口并重新启动。

## 当前边界

- 登录、支付、身份审核是课程演示，不产生真实账号或交易。
- 附件主要保存在当前浏览器，不是正式云文件存储。
- 屏幕共享尚未完整实现。
- `trycloudflare.com` 只用于临时联调，不是正式部署。
- 未配置 TURN 时，复杂网络下视频可能无法直连。

## 故障排查

### 启动闪退

只双击 `启动SkillS本地版.cmd`，不要直接打开 HTML。失败时窗口会保留错误；查看 `runtime` 日志。

### 手机打不开

优先用 HTTPS 地址。局域网方式需两端同一 Wi-Fi、关闭访客隔离，并允许 Node.js 通过 Windows 专用网络防火墙。

### HTTPS 地址未生成

确认电脑能联网，安全软件未阻止 `tools/cloudflared.exe`，然后查看 `runtime/tunnel.err.log`。

### 服务者看不到订单

确认两端地址完全相同，等待 1.5 秒，并确认订单尚未被其他设备接单。

### 手机错误地自动进入聊天

当前代码只允许后端返回 `accepted` 后跳转。若仍看到旧流程，请强制刷新或清除该临时站点缓存后重试。
